You will see a claim from a scientific paper. Split it into 2 shorter
sub-claims that together cover the original. Each sub-claim should be a
standalone factual assertion, useful as a retrieval query on its own.

If the claim is already simple and cannot be meaningfully split,
return just 1 sub-claim identical to the original.

Ignore citation markers like [1] or (Smith, 2020).

Return JSON:
{
  "sub_claims": ["<sub-claim 1>", "<sub-claim 2>"]
}
